# Skipper + STM32CubeIDE

---

### STM32CubeIDE Compatibility

#### The Skipper is designed to work seamlessly with the STM32CubeIDE. Follow the steps below to get set up.

---

### What is in this directory?

#### This directory includes a project template and examples to get you started using your Skipper with STM32CubeIDE.

- **Skipper template** — a ready-to-use project template. Copy this folder to start a new project.
- **Examples** — example projects demonstrating specific features of the Skipper.

---

### First Steps:

---

1. Download and install [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html).

2. Open STM32CubeIDE and select a workspace.

3. Import a project:

    1. Click **File > Open Projects from File System...**

    2. Click **Directory** and navigate to the `Skipper template` or an example folder inside this directory.

    3. Click **Finish**.

4. Connect your STM32 Skipper via the SWD port using an ST-Link programmer.

5. Click the **Run** button to build and flash the project.

---

#### For instructions regarding specific examples and functionality, refer to the `Examples` folder.
